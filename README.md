# oecd-inequality-analysis
# OECD Ülkelerinde Yeşil Karmaşıklık ve Gelir Eşitsizliği Analizi

## Proje Hakkında (Overview)
Bu proje, 27 OECD ülkesinin 2014-2023 yıllarını kapsayan panel veri seti kullanarak, yeşil teknoloji karmaşıklığı (GCI) ile gelir eşitsizliği (Gini) arasındaki ilişkiyi araştırmaktadır.

## Kullanılan Yöntemler (Methodology)
- **Panel Veri Modelleri**: Sabit Etkiler (FE), Rassal Etkiler (RE), Between ve Havuzlanmış (Pooled) OLS.
- **Tanı Testleri**: Hausman, Wooldridge, Pesaran CD, Değiştirilmiş Wald.
- **Sağlamlık Kontrolleri**: Kümelenmiş (clustered) standart hatalar, alt-örneklem analizleri.

## Dosya Yapısı (Files)
- `analysis.R` : Tüm R kodlarını içeren ana betik.
- `README.md` : Bu dosya.

## Nasıl Çalıştırılır? (How to Run)
1. R veya RStudio'yu açın.
2. Bu dosyaları bir klasöre kaydedin.
3. `analysis.R` dosyasını çalıştırın.
